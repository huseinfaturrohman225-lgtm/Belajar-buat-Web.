01 — KENALI LEBIH DEKAT

Apa itu Data Analysis?

Data Analysis adalah proses mengolah dan memeriksa data untuk menemukan informasi, pola, dan kesimpulan yang berguna.

Data yang awalnya hanya berupa angka atau catatan dapat menjadi informasi yang lebih bermakna setelah dikumpulkan, dibersihkan, dianalisis, lalu disajikan secara tepat.

✳

Tujuan utamanya: membantu kita memahami apa yang terjadi dan menentukan langkah selanjutnya berdasarkan data.

03 — TOOLS & TUGAS

Alat yang dipakai, pekerjaan yang dilakukan.

Tools yang digunakan dalam proses analisis data dan tugas yang dikerjakan di setiap tahapnya.

A Tools yang dipakai

XLS

Excel / Google Sheets

Mengumpulkan, merapikan, dan menghitung data awal dengan rumus, pivot table, dan grafik sederhana.

SQL

SQL

Melakukan query dan manipulasi database: memilih, menyaring, menggabungkan (JOIN), dan merangkum data.

PY

Python: Pandas, NumPy, Matplotlib

Pandas dan NumPy untuk membersihkan serta menghitung data, Matplotlib untuk membuat grafik.

BI

Tableau / Power BI / Looker Studio

Membangun dashboard interaktif agar hasil analisis mudah dipahami dan dibagikan.

ΣG

Statistik dasar & Git (opsional)

Statistik dasar (rata-rata, median, korelasi) untuk membaca data, dan Git untuk mencatat versi pekerjaan.

B Tugas yang dilakukan

  1. 01

    Mengumpulkan & merapikan data

    Menyusun data mentah di Excel / Google Sheets, lalu memeriksa kolom kosong dan duplikat.

  2. 02

    Query & manipulasi database

    Menulis query SQL untuk mengambil, menyaring, dan menggabungkan data dari beberapa tabel.

  3. 03

    Membersihkan & mengolah data

    Memakai Pandas dan NumPy untuk mengubah tipe data, menangani nilai hilang, dan menghitung agregat.

  4. 04

    Analisis statistik dasar

    Menghitung total, rata-rata, median, dan melihat tren serta hubungan antar variabel.

  5. 05

    Visualisasi & dashboard

    Membuat grafik dengan Matplotlib, lalu menyajikannya di Tableau, Power BI, atau Looker Studio.

  6. 06

    Menyimpulkan insight & dokumentasi

    Merangkum temuan utama dan menyimpan versi pekerjaan dengan Git bila diperlukan.
