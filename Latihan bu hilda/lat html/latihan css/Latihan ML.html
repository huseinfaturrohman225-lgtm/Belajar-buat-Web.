Machine Learning

Sistem yang belajar dari data
untuk membuat prediksi atau keputusan

Apa itu machine learning?

Machine Learning (pembelajaran mesin) adalah cabang dari kecerdasan buatan yang membuat
komputer mampu belajar dan data, tanpa harus diberi aliran yang ditulis manual untuk setiap kasus. Kalau pada pemrograman biasa kita menulis aturan lalu komputer menjalankannya, pada machine learning kita memberi contoh data dan komputer mencari sendiri polanya.

Bayangkan tilter spam di emall. tidak mungkin programmer menulis aturan untuk semua kalımat penipuan yang ada. Sebagai gantinya, sistem diberi ribuan email yang sudah ditandai "spam" atau "bukan spam",lalu belaiar ciri-ciri keduanya. Setelah itu sistem bisa menebak email baru yang belum pernah ia lihat. Hasil tebakan inilah yang disebut prediksi, dan tindakan yang diambil dari prediksi itu (misalnya memindahkan email ke folder spam) disebut prediksi

Cara Kerja Secara Umum

Setiap proyek machine learning pada dasarnya mengikuti alur yang mirip. Berikut tahapan
yang bisa dilakukan:

  1. mengumpulkan data
  2. membersihkan data
  3. Memilih Model
  4. Melatih Model
  5. Menguji Model
  6. menggunakan model

Jenis-Jenis Machine Learning

Machine learning dibagi menjadi beberapa jenis, diantaranya:

Jenis Cara Belajar Contoh Penggunaan
Super vised learning Belajar dari data yang sudah berlabel
(ada jawaban benarnya).		 Prediksi harga rumah,deteksi email spam
unsupervised learning Mencari pola atau kelompok pada data tanpa label Pengelompokan pelanggan toko online
reinforcement learning Belajar lewat coba-coba dengan hadiah dan hukuman Program permainan Catur,robot yang belajar berjalan

Contoh Penerapan Machine Learning

Beberapa contoh penerapan machine learning di kehidupan sehari-hari antara lain:

  • Pengenalan Wajah (Face Recognition)
  • Pendeteksi Spam Email
  • Sistem Rekomendasi (Recommendation System)
  • Pendeteksi Penipuan (Fraud Detection)
  • Penerjemah Bahasa (Language Translation)
